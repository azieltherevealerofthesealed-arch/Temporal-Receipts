# Intent

Temporal Receipts exists to preserve **sequence and provenance** without asserting truth, meaning, authority, or interpretation.

This project was created to:
- Separate *when something was recorded* from *what people think it means*
- Prevent historical overwrite
- Make disagreement visible rather than resolved by power

This system:
- Does not determine truth
- Does not arbitrate disputes
- Does not rank importance
- Does not enforce consensus

Misuse is possible.
Manipulation is possible.
Both are intentionally visible.

Temporal Receipts records time — nothing more.
